# ПТК «Предиктивный мониторинг инцидентов АСУ ТП»

**Разработчик:** Ведущий инженер по АСУП А.И. Акчиу
**Стек технологий:** Python 3.10+, PySide6 (Qt6), SQLite3
---
Cокращения:
ПТК - Программно-технический комплекс
ГПА - Газоперекачивающий агрегат
ПАЗ - Противоаварийная защита
КИПиА - Контрольно измерительные приборы и автоматика
---

## 1. Описание проекта
ПТК предназначен для автоматизированного анализа суточных ведомостей (логов) работы ГПА. 
В отличие от реактивных систем ПАЗ, данный комплекс реализует **алгоритм предиктивного анализа**. Он сканирует плотность аварийных тегов КИПиА во времени с помощью скользящего окна и выявляет скрытые каскадные сбои до момента жесткого останова оборудования.

## 2. Структура проекта в репозитории
*   `database.py` — модуль СУБД SQLite (архитектура таблиц, индексы, SQL-метрики KPI)
*   `log_parser.py` — автоматический парсер промышленных текстовых выгрузок SCADA
*   `main.py` — графический пульт оператора на PySide6 (таблицы, карточки надежности, алерты)
*   `test_run.py` — консольный скрипт первичной проверки и наполнения базы данных
*   `scada_export.log` — файл реальной технологической выгрузки (50 инцидентов смены)
*   `requirements.txt` — перечень зависимостей для развертывания.

## 3. Инструкция по развертыванию и запуску

### Шаг 1. Активация виртуального окружения (.pyside)
```bash
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process
.pyside\Scripts\Activate.ps1
```

### Шаг 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### Шаг 3. Инициализация БД и парсинг логов
```bash
python test_run.py
```

### Шаг 4. Запуск диспетчерского пульта
```bash
python main.py
```
